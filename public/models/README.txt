=== EWENBUILDS.xyz 3D ASSETS DIRECTORY ===
Place your interactive 3D model files (.glb or .gltf) here.
Google's <model-viewer> web component loads them statically from /models/[filename].glb.

Expected file paths referenced in the website:
- public/models/[INSERT 3D MODEL FILE].glb
- public/models/hexapod-robot-chassis.glb
- public/models/macro-dial-case.glb

Tip: Keep .glb files under 15MB for rapid initial loading. Use Blender or glTF-Transform for Draco mesh compression.
