=== EWENBUILDS.xyz STATIC DOWNLOADS REPOSITORY ===
Place your project distribution files here so Vite copies them automatically to /dist/downloads/.

Suggested Files to place here:
1. public/downloads/[INSERT PROJECT NAME].zip
   -> Complete project archive with source code, schematic PDFs, and build instructions.
2. public/downloads/[INSERT CAD STL STEP FILE].zip
   -> 3D printable STL files and STEP neutral CAD exports.
3. public/downloads/[INSERT FIRMWARE BINARY].bin or .hex
   -> Precompiled binaries for microcontrollers (ESP32, RP2040, STM32).
